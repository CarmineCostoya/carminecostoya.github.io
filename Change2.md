# Change 2: Improve Navigation and Accessibility

## Goal

Make the portfolio easier to navigate and scan on phones, desktops, and keyboards while preserving the simple editorial character.

## Planned changes

- Show the current page in the primary navigation with both visual styling and `aria-current`.
- Make the header persistent and improve navigation touch targets and mobile wrapping.
- Add an in-page index to the Work Experience page so visitors can jump directly to an organization.
- Strengthen section hierarchy, focus treatment, anchor positioning, and calls to action.

## Expected result

Visitors should always know where they are, reach any primary page or employer quickly, and complete the full experience with a keyboard or a narrow mobile viewport.
